# Abiotic Factor Mod Manager - Source

This is the unbuilt WinUI 3 source package. It is separate from the self-contained Windows release.

## Build

On Windows x64 with the .NET 8 SDK and NuGet access:

1. Extract this folder.
2. Run Build.ps1 from the extracted folder.

The build script builds and publishes a self-contained WinUI 3 app, includes the compiled XAML resources and portable helper scripts, and retains only the English (en-us) resource satellite.

## Contents

- Source.WinUI contains the app source, project file, manifest, and icon.
- Build.ps1 builds the app and assembles the portable app folder.
- SteamLaunchWrapper.ps1 handles Steam launches and reads manager-owned Mod.io arguments plus the optional additional launch arguments.
- Uninstall.bat launches Uninstall.ps1.
- Data is generated by the app on first run and is not part of this source package.

User settings, API keys, installed-mod lists, manual mod packs, build caches, and backups are generated locally and are not included.
