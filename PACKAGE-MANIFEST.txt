Abiotic Factor Mod Manager 0.0.1 - Windows x64 release package.
Self-contained portable application for managing Mod.io sideload mods and UE4SS mods together.
Extract the complete archive into a folder of your choice and run AbioticFactorModManager.exe.
English (en-us) resources only.
The application creates its Data folder alongside the executable when first run.
No previous-install migration or personal game-file patches are included.
