# Abiotic Factor Mod Manager 0.0.1

Download the files below from the GitHub Releases page:

- **AbioticFactorModManager-0.0.1-Windows-x64.7z** - the ready-to-run Windows x64 application. Extract the complete archive and launch **AbioticFactorModManager.exe** from the main folder. The application and its runtime files are grouped in the **App** subfolder.
- **AbioticFactorModManager-0.0.1-Source.zip** - the unbuilt WinUI source package.

The manager handles Mod.io sideload mods and UE4SS mods together. For Steam users, saving additional launch options will offer to install the required Steam launch setup if it is not already configured. Steam launches through a hidden helper, so the PowerShell wrapper does not create a visible console window.

See the repository README for installation, mod-management, Steam setup, and uninstall instructions. SHA256SUMS.txt contains checksums for both downloads.
